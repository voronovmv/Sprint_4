# Тесты для BooksCollector

В этом проекте написаны unit-тесты для класса 'BooksCollector' с использованием 'pytest'.
Тесты проверяют базовую логику работы с книгами: добавление, назначение жанров и работу со списком избранного.

# Что проверяется

# Добавление книг
Проверяется, что:
- книга с корректным названием добавляется в коллекцию;
- книга с пустым названием или названием длиннее 40 символов не добавляется;
- одну и ту же книгу нельзя добавить повторно;
- у новой книги жанр по умолчанию пустой.

# Назначение и получение жанра
Проверяется, что:
- жанр корректно устанавливается для существующей книги, если жанр допустим;
- жанр не устанавливается, если книги нет в коллекции;
- жанр не устанавливается, если он отсутствует в списке допустимых;
- жанр книги можно получить по её названию.

# Работа с жанрами
Проверяется, что:
- метод возвращает только книги с указанным жанром;
- метод получения словаря жанров возвращает актуальное состояние коллекции;
- книги с возрастным рейтингом не попадают в список книг, подходящих для детей.

# Работа с избранным
Проверяется, что:
- в избранное можно добавить только книгу, которая есть в коллекции;
- одну и ту же книгу нельзя добавить в избранное дважды;
- книгу можно удалить из избранного;
- список избранных книг возвращается корректно.
